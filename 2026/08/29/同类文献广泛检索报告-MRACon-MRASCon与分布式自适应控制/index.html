同类文献广泛检索报告：MRACon、MRASCon 与分布式自适应控制

检索日期：2026-08-29

1. 文件夹论文的共同研究画像

文件夹中的论文主要落在以下交叉方向：

  1. 有向图或切换有向图上的多智能体一致性、同步、编队与包容控制；
  2. 不确定、异构、非线性或未知动力学下的分布式自适应控制；
  3. 模型参考自适应控制（MRAC）、模型参考自适应一致性（MRACon）与模型参考自适应稳定化一致性（MRASCon）；
  4. 全分布式设计，即不依赖 Laplacian 特征值、网络规模等全局信息；
  5. DREM、协同持续激励/有限时间激励、参数收敛与有限时间辨识；
  6. 输出反馈、分布式观测器、包容控制；
  7. 被动性分析、事件触发、滑模、未知控制方向与 Nussbaum 增益。

最强的主题主线是：MRACon/MRASCon + 有向支撑树 + 不确定异构线性系统 + 全分布式/参数辨识 + 输出反馈扩展。

2. 第一优先级：与 MRACon / MRASCon 最接近

2021 Closed-Loop Reference Model Based Distributed Model Reference Adaptive Control for Multi-Agent Systems 闭环参考模型 CRM、分布式 MRAC、改善暂态性能 可与 MRASCon 的误差反馈机制比较

2023 Leader-Following Consensus of a Class of Heterogeneous Uncertain Multi-Agent Systems with a Distributed Model Reference Adaptive Control Law 异构不确定系统、分布式 MRAC、领导跟随 与文件夹中的领导跟随 MRASCon 直接对照
2023 D-MRACO: Decentralized Model Reference Adaptive Controller and Observer 输出反馈、去中心化 MRAC 控制器与观测器、统一处理无领导/领导跟随 文件夹“输出反馈包容控制”工作的直接基础

2025 Nonlinear Model Predictive Control for Leaderless UAV Formation Flying with Collision Avoidance under Directed Graphs 直接采用 MRACon 分层框架，将参考模型与 NMPC/安全约束结合 展示 MRACon 从理论到硬件实验的应用扩展
2026 Event-Triggered Coordinated Tracking for Heterogeneous Multiagent Systems with Unknown Dynamics Using Model Reference Adaptive Control MRAC、未知异构动力学、事件触发、状态/输出反馈两种协议 最新且高度相关，优先跟踪正式卷期与 DOI

8. 推荐阅读顺序

若目标是继续推进文件夹中的“全分布式 MRASCon / 输出反馈包容 / DREM 参数辨识”研究，建议顺序为：

  1. Baldi–Yuan–Frasca 2019（分布式模型参考自适应同步）；
  2. Mei–Ren–Song 2021（MRACon，文件夹已有）；
  3. Azzollini 等 2021（无额外分布式观测器）；
  4. Goel–Garg–Roy 2022（CRM-DMRAC + 协同初始激励）；
  5. Yue 等 2023 D-MRACO（输出反馈统一框架）；
  6. Yue 等 2024/2025 MRASCon（文件夹已有）；
  7. Matveev 等 2022 + Yuan 等 2021（DREM/协同有限时间激励）；
  8. Guo–Zhang–Zhang 2025（全分布式输出反馈间接 MRAC）；
  9. 2025 输出包容论文与 2026 事件触发 MRAC 论文。

9. 从现有文献看最值得继续做的空白

  1. 全分布式无领导 MRASCon：在一般含有向支撑树图上去除左特征向量、最小非零特征值或根节点全局结构信息，同时处理不稳定参考动力学。
  2. 输出反馈 MRASCon：把 D-MRACO/MRACO 与 MRASCon 结合，避免状态可测假设，并明确是否需要额外分布式观测器。
  3. 参数收敛型 MRASCon：用 DREM、协同 IE/FTE 或复合学习保证真实参数收敛，而不仅是跟踪误差收敛和参数有界。
  4. 切换有向图与暂态性能：同时保证一致性、参数辨识和显式收敛速率，特别是统一联合连通图下的结论。
  5. 包容控制的 MRACO/MRASCon 化：多领导者凸包参考模型 + 输出反馈 + 未知异构/非最小相位动力学。
  6. 约束与安全：将 MRACon/MRASCon 与 MPC、控制障碍函数、事件触发或抗攻击机制组合，并给出严格闭环证明。

  • "model reference adaptive consensus" OR MRACon OR MRASCon
  • "distributed model reference adaptive control" multi-agent
  • "fully distributed" adaptive consensus directed spanning tree uncertain
  • DREM distributed parameter estimation directed graph multi-agent
  • cooperative finite-time excitation adaptive containment control
  • output feedback indirect MRAC multiagent
  • unknown heterogeneous multi-agent output containment adaptive
  • passivity nonlinear consensus balanced digraph
  • event-triggered sliding-mode consensus unknown perturbations directed graph

检索时应继续沿两条引用链扩展：一是从 Mei–Ren–Song 2021 向前追溯 MRAC/MRACon 基础，向后追踪 MRASCon、D-MRACO、输出反馈与应用论文；二是从 DREM-MRACon 2025 向前追溯 DREM、协同激励与分布式参数估计，向后追踪参数收敛型一致性控制。
