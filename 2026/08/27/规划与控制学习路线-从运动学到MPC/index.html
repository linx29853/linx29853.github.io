规划与控制学习路线：从运动学到 MPC

发表于2026-08-27|更新于2026-08-27|技术学习
|浏览量:

适用人群：具备 Python、线性代数和基础微积分，希望进入机械臂规划、控制、机器人操作或具身智能方向的学习者。
建议周期：10 周，每周 8–12 小时。
主线平台：Python + MuJoCo；需要 ROS 工程能力时再扩展到 ROS 2、MoveIt 2 与 Gazebo。
最终成果：完成一个机械臂避障运动与轨迹跟踪项目，提交可复现代码、指标曲线、演示视频和实验报告。

1. 学习目标

完成本路线后，应能够：

  1. 使用齐次变换描述机器人与物体之间的位姿关系；
  2. 求解机械臂正运动学、逆运动学与雅可比矩阵；
  3. 区分路径、轨迹和控制，生成速度与加速度连续的参考轨迹；
  4. 理解机器人动力学方程，并实现 PID、重力补偿或计算力矩控制；
  5. 使用 A*、RRT、RRT* 或 PRM 生成无碰路径；
  6. 理解 TrajOpt、iLQR、MPC 和 MPPI 的适用边界；
  7. 将“路径规划—轨迹生成—闭环控制—评测”组成完整系统。

推荐的知识依赖关系如下：

2. 开始前的先修检查

2.1 数学

  • 能进行矩阵乘法、求逆、特征值和线性方程求解；
  • 理解导数、偏导数、梯度与链式法则；
  • 知道均值、方差和高斯分布的基本含义；
  • 能理解常微分方程描述的动态系统。

2.2 编程与工具

  • 能用 Python 编写函数、类和简单数值实验；
  • 熟悉 NumPy、Matplotlib；
  • 能创建独立环境、安装依赖并保存实验配置；
  • 了解 Git 的基本使用方法。

2.3 建议的补课入口

  • 机器人学打底
  • 工程环境：Conda、Docker、日志与可视化
  • Modern Robotics 课程与教材
  • MIT Underactuated Robotics

如果暂时不会 ROS，不需要在开始本路线前专门补完。前 8 周可全部在 Python 和 MuJoCo 中完成。

3. 十周执行计划

第 1 周：坐标系与刚体变换

目标

  • 掌握旋转矩阵、欧拉角、轴角与四元数的用途；
  • 理解齐次变换矩阵以及变换的组合、求逆；
  • 能在世界、基座、末端和物体坐标系之间转换位姿。

必学资料

  • 仓库：机器人学打底——坐标系与齐次变换
  • 仓库：第三章公式汇总
  • Modern Robotics：第 2、3 章

实践任务

  1. 用 NumPy 实现旋转矩阵和齐次变换矩阵；
  2. 实现 compose(T_ab, T_bc) 与 inverse(T_ab)；
  3. 随机生成 20 组变换，与 scipy.spatial.transform 的结果比较。

验收标准

  • 旋转矩阵满足正交性，行列式接近 1；
  • 组合变换和逆变换的数值误差小于 1e-6；
  • 能解释左乘、右乘以及变换方向混淆的常见错误。

第 2 周：正运动学与机器人建模

目标

  • 理解串联机械臂的运动链；
  • 掌握 DH 参数与正运动学；
  • 能根据关节角计算末端位姿。

必学资料

  • 仓库：机器人学打底——正逆运动学与 DH 参数
  • Robotics Toolbox for Python
  • Modern Robotics：第 4 章

实践任务

  1. 实现二维二连杆正运动学；
  2. 绘制不同关节角下的机械臂姿态；
  3. 建立一个 6 自由度机械臂模型，并与工具箱结果交叉验证。

验收标准

  • 能由关节角稳定计算末端位置和姿态；
  • 手写结果与工具箱结果一致；
  • 能说明 DH 参数的四个量分别描述什么。

第 3 周：逆运动学、雅可比与奇异点

目标

  • 理解逆运动学的多解、无解和数值求解；
  • 掌握雅可比矩阵的几何意义；
  • 能识别不可达目标和奇异构型。

必学资料

  • 仓库：机器人学打底——逆运动学与雅可比
  • Modern Robotics：第 5、6 章

实践任务

  1. 推导二维二连杆的肘上、肘下解析 IK；
  2. 实现基于雅可比伪逆的数值 IK；
  3. 绘制工作空间，并标记不可达区域和奇异位置；
  4. 比较解析法、普通伪逆和阻尼最小二乘法。

验收标准

  • 可到达目标的末端位置误差小于设定阈值；
  • 不可达目标能够正确退出，而不是无限迭代；
  • 能通过雅可比秩或条件数解释奇异性。

阶段里程碑 A：完成一个可交互的二维机械臂 FK/IK 可视化程序。

第 4 周：路径、时间参数化与轨迹生成

目标

  • 区分路径、轨迹和控制；
  • 掌握关节空间与笛卡尔空间规划的差异；
  • 实现三次、五次多项式和梯形速度曲线。

必学资料

  • 仓库：机器人学打底——轨迹规划对比
  • Modern Robotics：第 9 章
  • MoveIt 时间参数化教程

实践任务

  1. 为单关节生成三次与五次多项式轨迹；
  2. 扩展到多关节同步运动；
  3. 绘制位置、速度、加速度曲线；
  4. 对比关节空间插值和笛卡尔空间插值的末端路径。

验收标准

  • 满足起止位置、速度和加速度边界条件；
  • 轨迹没有数值跳变；
  • 能解释为什么几何路径不能直接发送给机器人执行。

第 5 周：机器人动力学

目标

  • 理解惯性矩阵、科氏/离心项、重力项和执行器力矩；
  • 掌握前向动力学与逆动力学的区别；
  • 理解模型参数误差如何影响控制效果。

机器人动力学的一般形式为：

$$
M(q)\ddot q + C(q,\dot q)\dot q + g(q) + f(\dot q) = \tau + J(q)^T F_{ext}
$$

必学资料

  • Modern Robotics：第 8 章
  • MIT Underactuated Robotics：Multi-Body Dynamics
  • MuJoCo 文档

实践任务

  1. 在二连杆模型上观察重力、惯量和阻尼的影响；
  2. 比较零力矩、重力补偿和指定力矩下的系统响应；
  3. 在 MuJoCo 中读取关节位置、速度和执行器输入并记录日志。

验收标准

  • 能说明动力学方程中每一项的物理意义；
  • 能区分运动学误差和动力学/控制误差；
  • 能从实验曲线判断阻尼不足、控制饱和等问题。

第 6 周：PID、前馈与计算力矩控制

目标

  • 掌握闭环反馈、稳定性、稳态误差和超调等概念；
  • 能完成单关节和多关节轨迹跟踪；
  • 理解反馈与模型前馈的分工。

必学资料

  • Control Tutorials for MATLAB and Simulink：PID
  • Modern Robotics：第 11 章
  • MuJoCo 入门资料

实践任务

依次实现并比较：

  1. P 控制；
  2. PD/PID 控制；
  3. PD + 重力补偿；
  4. 计算力矩控制。

每组实验记录峰值误差、均方根误差、超调量和稳定时间。

验收标准

  • 在不发生持续震荡的情况下完成轨迹跟踪；
  • 能根据误差曲线调整增益；
  • 加入模型前馈后，跟踪误差有可解释的改善。

第 7 周：搜索与采样式路径规划

目标

  • 理解配置空间、碰撞检测和可行路径；
  • 掌握 A*、PRM、RRT 与 RRT* 的基本思想；
  • 能对规划器进行可重复的量化比较。

必学资料

  • Planning Algorithms（Steven M. LaValle）
  • OMPL 官方文档
  • MoveIt 2：OMPL 规划器

实践任务

  1. 在二维障碍环境实现 A*；
  2. 实现或调用 RRT 与 RRT*；
  3. 将规划问题扩展到机械臂关节空间；
  4. 以固定随机种子重复至少 20 次实验。

验收标准

  • 生成的路径无碰撞且满足关节限位；
  • 报告成功率、平均规划时间、路径长度和路径平滑度；
  • 能解释 RRT 与 RRT* 在速度和路径质量上的取舍。

第 8 周：轨迹优化与 iLQR

目标

  • 理解将规划写成优化问题的方法；
  • 掌握代价函数、约束、初始轨迹和局部最优；
  • 理解 TrajOpt 与 iLQR 的差异。

必学资料

  • 仓库：轨迹优化与实时控制
  • MIT Underactuated Robotics：Trajectory Optimization
  • Drake：Trajectory Optimization

实践任务

  1. 对第 7 周生成的路径加入长度、平滑度和障碍距离代价；
  2. 比较原始 RRT 路径与优化后轨迹；
  3. 在二连杆或小车模型上运行 iLQR；
  4. 改变初始轨迹，观察收敛结果。

验收标准

  • 优化后的轨迹仍然满足碰撞和关节约束；
  • 至少一个平滑度或路径长度指标得到改善；
  • 能解释初始值为什么会影响局部优化结果。

阶段里程碑 B：形成“采样规划器给初值，轨迹优化器做平滑”的完整管线。

第 9 周：LQR、MPC 与 MPPI

目标

  • 理解有限时域代价、滚动优化与反馈控制；
  • 掌握 MPC “预测—优化—执行第一步—重新规划”的循环；
  • 理解优化型 MPC 与采样型 MPPI 的差异。

必学资料

  • 仓库：iLQR、MPPI、MPC 与 TrajOpt
  • MIT Underactuated Robotics：LQR
  • do-mpc 文档
  • CasADi 文档

实践任务

  1. 在线性小车或二连杆局部线性模型上实现 LQR；
  2. 使用 CasADi 或 do-mpc 实现带输入限制的 MPC；
  3. 比较 PID 与 MPC 的跟踪误差、求解时间和扰动恢复；
  4. 选修：实现简化 MPPI，研究采样数和预测时域的影响。

验收标准

  • MPC 显式满足输入或状态约束；
  • 平均求解时间满足所设控制周期；
  • 能根据系统非线性、约束和实时性选择 iLQR、MPC 或 MPPI。

第 10 周：综合项目与报告

完成一个机械臂避障运动与轨迹跟踪系统：

必做对比

  1. RRT 与 RRT*：成功率、规划时间、路径长度；
  2. 三次与五次轨迹：速度、加速度连续性；
  3. PID 与 MPC：均方根误差、最大误差、扰动恢复时间；
  4. 至少一种失败情形：窄通道、奇异点、不可达目标、控制饱和或模型误差。

交付物

  • README.md：问题、环境、运行步骤和主要结果；
  • 环境与依赖文件；
  • 规划、轨迹生成、控制和评测代码；
  • 位置、速度、加速度、控制量和误差曲线；
  • 至少一段完整演示视频；
  • 3–5 页实验报告，包含方法、指标、对比、失败分析与下一步计划。

建议验收指标

指标 基础目标 进阶目标
静态场景规划成功率 ≥ 90% ≥ 98%
轨迹碰撞率 0 0
关节限位违规次数 0 0
归一化轨迹跟踪 RMSE ≤ 5% ≤ 2%
扰动后恢复 能恢复 恢复时间可量化并优于基线
实验可复现性 固定配置可复现 多随机种子报告均值与方差

指标应根据具体机器人、任务尺度和控制周期调整。若调整，需要在报告中写清定义与原因。

4. 仿真与工具选型

4.1 默认选择：MuJoCo

适合快速验证机械臂动力学、接触和控制算法，依赖相对轻量。推荐完成本路线的前 9 周后，再决定是否迁移平台。

  • 仓库：MuJoCo 介绍与入门
  • MuJoCo 官方文档

4.2 ROS 2 + MoveIt 2 + Gazebo

适合希望获得机器人软件工程、通信、硬件接口和完整规划栈经验的学习者。建议在综合项目已经能在 MuJoCo 中运行后再迁移。

  • 仓库：Gazebo
  • MoveIt 2 Tutorials
  • Gazebo Documentation

4.3 Isaac Lab

适合具备 NVIDIA GPU、后续计划进行大规模强化学习、人形机器人或 Sim2Real 的学习者。它不是本路线的必需平台。

  • 仓库：Isaac Lab 入门
  • 仓库：Isaac Lab 任务与日志

4.4 常用 Python 工具

用途 工具 使用建议
数值计算 NumPy、SciPy 前 4 周主要工具
可视化 Matplotlib 所有实验必须输出曲线
机器人学 Robotics Toolbox for Python 用于验证手写运动学结果
仿真 MuJoCo 默认物理引擎
采样规划 OMPL 第 7 周后使用
优化与 MPC CasADi、do-mpc 第 8–9 周使用
ROS 规划栈 MoveIt 2 工程分支选修

5. 方法选择速查

方法 主要用途 优势 主要限制
A* 低维离散空间搜索 完备、易理解 高维空间开销大
PRM 多次查询的配置空间规划 路网可复用 建图成本高
RRT 高维空间快速找可行解 找路快、实现直观 路径通常不平滑
RRT* 渐近最优规划 路径质量更高 收敛较慢
TrajOpt 带约束轨迹平滑与优化 轨迹短且平滑 依赖初始值、局部最优
iLQR 已知动力学下的局部轨迹优化 结构化、收敛较快 约束处理能力有限
MPC 在线多变量约束控制 能显式考虑预测与约束 实时求解成本高
MPPI 非线性系统采样控制 无需代价梯度、便于并行 采样量和调参成本高

一个实用的机械臂系统通常不是只选一种方法，而是：

RRT/RRT* 寻找可行路径 → TrajOpt 平滑 → 时间参数化 → PID/计算力矩/MPC 闭环执行。

6. 每周学习节奏

以每周 10 小时为例：

环节 建议时间 要求
阅读与推导 2 小时 只推导本周实践真正需要的公式
最小实现 3 小时 先在二维或低自由度系统验证
仿真实验 3 小时 固定随机种子，保存配置和日志
复盘与整理 2 小时 输出图表、结论和失败原因

每周至少保留以下记录：

  • 本周问题与假设；
  • 实验配置和随机种子；
  • 一张结构图或流程图；
  • 两张以上指标曲线；
  • 一个成功案例与一个失败案例；
  • 下周需要解决的一个明确问题。

7. 学习边界与常见误区

  1. 不要同时学习所有仿真平台：先用一个平台完成闭环，再迁移。
  2. 不要把路径直接当轨迹执行：路径缺少时间、速度和加速度信息。
  3. 不要只看动画判断控制效果：必须记录误差、控制量、求解时间和约束违规。
  4. 不要只在一个初始状态上测试：使用多组目标、多随机种子和扰动。
  5. 不要过早追求完整六轴推导：先在二连杆上理解原理，再调用成熟库处理复杂模型。
  6. 不要忽略单位与坐标系：角度/弧度、毫米/米和变换方向是最常见的工程错误。
  7. 不要直接跳到 MPC：若尚不能稳定实现 PID 轨迹跟踪，很难判断 MPC 的改进来自哪里。

8. 完成后的方向分流

  • 机械臂操作与 VLA：继续学习模仿学习、Diffusion Policy和VLA，重点理解学习策略输出与底层控制的接口。
  • 人形机器人运控：继续学习运控综述、Isaac Lab、全身控制和 Sim2Real。
  • 移动机器人与导航：转向状态估计、SLAM、全局/局部规划和具身导航综述。
  • 接触与精密装配：继续学习阻抗/导纳控制、力矩传感、触觉和力控与触觉路线。
  • 最优控制研究：深入非线性 MPC、鲁棒 MPC、随机最优控制、系统辨识和安全约束。

9. 最终检查清单

  • 我能独立实现并验证二维机械臂 FK/IK；
  • 我能解释雅可比、奇异点和阻尼伪逆；
  • 我能生成满足边界条件的平滑轨迹；
  • 我能在仿真中完成稳定的闭环轨迹跟踪；
  • 我能生成机械臂无碰路径并进行时间参数化；
  • 我能解释 RRT、TrajOpt、iLQR、MPC、MPPI 的适用边界；
  • 我的实验包含量化指标和失败分析；
  • 其他人可以根据 README 复现实验；
  • 我已完成综合项目的代码、报告和演示视频。
